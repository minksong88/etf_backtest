# ETF 자금흐름 × 가격 다이버전스 백테스트

> **질문:** ETF 펀드플로우로 `flow/AUM` 자금유입률을 구하고 '평소 대비' z-score를 낸 뒤,
> **가격 추세와 자금유입률이 어긋나는 다이버전스**를 천장/바닥 신호로 쓸 수 있는가?
>
> - *"ETF는 상승 중인데 자금유입은 약함/유출"* → 이후 하락(천장) 신호인가?
> - *"ETF는 하락 중인데 자금유입은 강함"* → 이후 반등(바닥) 신호인가?

**한 줄 답:** 대체로 **아니다 — 그리고 바닥 가설은 정반대로 작동한다.** 아래 참조.

---

## TL;DR — 결론 3가지

전체 유니버스(플로우 존재 ETF 65개), 2022–2026, **시장중립(유니버스 횡단면 평균 제거)** 초과수익 기준:

| 시그널 (정의) | 5일 | 10일 | 20일 | 60일 |
|---|---|---|---|---|
| **bear_div** — 가격↑ + 자금 약함/유출 *(천장 가설)* | **−0.18%** ᵗ⁻³·⁵ | **−0.16%** ᵗ⁻²·³ | ~0 | ~0 |
| **bull_div** — 가격↓ + 자금 강함 *(바닥 가설)* | −0.06 | −0.17 | **−0.52%** ᵗ⁻⁴·¹ | **−1.03%** ᵗ⁻⁴·⁴ |
| **confirm_up** — 가격↑ + 자금 강함 | +0.09 ᵗ²·⁴ | +0.11 ᵗ²·² | **+0.25%** ᵗ³·⁵ | +0.20 ᵗ¹·⁷ |
| confirm_dn — 가격↓ + 자금 유출 | ~0 | ~0 | −0.12 | +0.29 ᵗ²·¹ |

(ᵗ = naive t-stat. 겹치는 이벤트라 과대평가 경향 → block-bootstrap 병행. `results/event_study.png`)

1. **"바닥 신호" 가설은 반대로 틀렸다.** 가격이 빠지는데 자금이 **강하게 유입**되는 ETF는
   반등하지 않고 **계속 언더퍼폼**한다(20일 −0.52%, 60일 −1.03%, t≈−4). 전체 연구에서
   **가장 강하고 일관된** 결과. 즉 "떨어지는데 돈 몰림 = falling knife", 추종 매수는 나쁜 자금.
2. **"천장 신호"는 단기(1~2주)로만 약하게** 성립. 자금이 약한 상승은 5~10일 소폭 눌리고(−0.18%)
   20일이면 희석된다. 전략적으로는 쓸 수 있으나 오래 못 간다.
3. 실제로 돈이 되는 축은 *다이버전스*가 아니라 **자금이 추세를 확인(confirm)할 때**다 —
   상승 + 유입(confirm_up)은 20일 +0.25%(t3.5)로 지속 초과수익.

> **함의:** 자금유입 z-score는 "역발상 바닥 지표"가 아니라 **모멘텀 확인/증폭 지표**에 가깝다.
> 자금이 가격과 같은 방향이면 순풍(confirm_up 롱), 자금이 하락을 거스르면 역풍(bull_div 숏).

## 업데이트 — SPY 초과수익 & 집계기간(W) 민감도

이 유니버스는 **멀티에셋**(주식섹터 + 금·은·원유·천연가스 + 비트코인)이라 횡단면 평균은
의미가 약하다 → 벤치마크를 **SPY 초과수익**으로 바꾸고, 자금·모멘텀 **집계기간 W**를 5/10/20일로
스윕했다. (`data/event_study_spy_windows.csv`, `results/windows_spy.png`)

**SPY 대비 초과수익(%) · 대표 셀 (괄호=t):**

| 신호 | 최적 W·호라이즌 | 결과 | 해석 |
|---|---|---|---|
| **confirm_dn** 하락+유출 | **W=5 · 20일** | **+0.37% (t4.1)** | **진짜 바닥/반등 = 급락+투매.** 짧게 볼수록 선명 |
| **confirm_up** 상승+유입 | W=10 · 5–10일 | +0.13~0.17% (t~3) | 단기 추세지속. 20일 넘으면 소멸 |
| **bull_div** 하락+유입 | W=20 · 60일 | −1.18% (t−4.9) | 바닥 아님, 계속 하락(falling knife) — 숏 |
| **bear_div** 상승+유출 | W=20 · 전 구간 | −0.27%/−0.78% (t−4) | 천장 — vs SPY 지속 언더퍼폼 |

**바뀐 그림:** "바닥 신호"는 존재하지만 사용자 원가설(*하락+유입*)이 아니라
**하락+유출(투매)** 이고, **집계기간을 짧게(W=5)** 볼 때 가장 선명하다.
"천장 신호"(상승+자금약함)는 반대로 **W=20**에서 vs SPY 뚜렷하다.

> ⚠️ SPY 기준은 이 니치 유니버스의 구조적 SPY 언더퍼폼 드리프트가 신호에 섞인다
> (특히 bear/bull_div의 지속 음수). 순수 알파는 위쪽 `demean`이 더 보수적이며 **방향성 결론은 동일**.
> `config.py`의 `bench_mode`('spy'|'demean')와 `flow_window`/`mom_window`(=W)로 전부 재현·조정 가능.

## 방법론

모든 피처는 **인과적**이다(시점 t 피처는 t까지 데이터만 사용). 정의는
`sql/build_panel.sql`(윈도우 함수)과 `flow_divergence/signals.py`(pandas)가 1:1로 동일하다.

- **일별 자금유입률**: `flow/AUM`
- **자금흐름 강도** `flow_intensity`: 최근 20거래일 순유입 합 ÷ 현재 AUM (일별 노이즈 평활)
- **자금 z-score** `flow_z`: `flow_intensity`를 자기자신의 **트레일링 252일** 분포로 표준화
  → "평소 대비" 강도. `|z|>1` 이면 평소보다 유의하게 강함/약함.
- **가격 모멘텀** `mom`: `px_t / px_{t-20} − 1` (상승/하락 추세)
- **시그널 4분면**: (mom 부호) × (flow_z 부호, 임계 1.0)
  - `bull_div` = 가격↓ + 자금 강함 · `bear_div` = 가격↑ + 자금 약함
  - `confirm_up` = 가격↑ + 자금 강함 · `confirm_dn` = 가격↓ + 자금 약함

**평가 — 룩어헤드 차단:** 시그널은 종가 t, 진입은 **종가 t+1**, 청산은 t+1+h.
(블룸버그 FUND_FLOW는 장 마감 후 집계 → 최소 1일 지연이 현실적.)

**벤치마크 주의:** 이 65개는 섹터·테마 ETF라 2022–2026에 SPY를 **구조적으로 언더퍼폼**했다
(neutral의 SPY-초과도 −0.15%/20일). 그래서 SPY 대비가 아니라 **같은 날 유니버스 평균을 뺀
횡단면 초과수익(=시장/베타 중립)** 으로 시그널 순수 알파를 측정한다. 이게 롱-숏이 실제로 먹는 부분.

## 재현 방법

DB에 직접 접근 가능한 환경(사용자 노트북/서버)에서:

```bash
pip install -r requirements.txt
export DATABASE_URL="postgresql://postgres.<ref>:<PW>@aws-0-ap-northeast-2.pooler.supabase.com:6543/postgres"
python run_backtest.py                 # 이벤트 스터디 + 롱숏 포트폴리오
python make_charts.py                  # results/*.png
```

### 산출물 현황

| 산출물 | 상태 | 비고 |
|---|---|---|
| 이벤트 스터디 (헤드라인) | ✅ 완료 · `data/event_study.csv` | 전체 65 ETF·전 구간 SQL 집계 |
| 이벤트 스터디 차트 | ✅ `results/event_study.png`, `hitrate_20d.png` | |
| 롱-숏 수익곡선 · 서브기간/파라미터 강건성 | ⏳ 코드 준비완료, `run_backtest.py`로 로컬 실행 | 아래 참조 |

> **왜 수익곡선이 미리 안 담겼나:** 이 저장소를 만든 샌드박스는 정책상 DB **직접 접속이
> 차단(403)**돼 Supabase **MCP 경유로만** 데이터 접근이 가능한데, 이 인스턴스(서울, 소형)에서
> `bbg×fmp` 조인이 무거워 MCP의 **60초 실행 제한**에 걸린다(콜드 캐시 시 조인 하나가 60초 초과).
> 헤드라인 이벤트 스터디는 캐시가 따뜻할 때 확보했다. 사용자 환경에서는 이 제약이 없으므로
> `python run_backtest.py` 한 방이면 수익곡선·Sharpe·서브기간·파라미터 그리드까지 전부 나온다.
> `flow_divergence/` pandas 구현은 `sql/build_panel.sql`과 정의가 1:1로 동일하다(합성데이터 검증 완료).

## 한계 · 주의

- **표본 5년(2022–2026):** 금리인상·AI랠리가 지배. 레짐 편향 가능 → 서브기간 확인 필요.
- **겹치는 이벤트:** naive t-stat은 유의성 과대평가 → block-bootstrap로 보정(`flow_divergence/stats.py`).
- **거래비용 미반영:** 섹터 ETF 스프레드/충격은 작지만, 회전율 고려 시 순알파는 축소.
- **배당 미조정 가격(PX_LAST):** XLU·XLP 등 고배당 ETF의 총수익과 소폭 차이(방향성엔 영향 미미).
- **생존/유니버스:** 상장폐지 ETF는 미포함(자금흐름 데이터 특성상 생존 ETF 위주).
